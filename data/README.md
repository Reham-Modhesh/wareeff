# قاعدة بيانات وريف: `wareef.db`

قاعدة بيانات SQLite في ملف واحد. تفتحها بـ [DB Browser for SQLite](https://sqlitebrowser.org/)، أو من Python بـ `sqlite3`، أو من أي لغة برمجة.

## المحتوى
| الجدول | وش فيه | العدد |
|---|---|---|
| `districts` | الأحياء (حطين، النرجس) وحدودها | 2 |
| `streets` | الشوارع، مجمّعة بالاسم | 2,995 |
| `street_ways` | مقاطع الشوارع الأصلية من OSM وخطها | 3,428 |
| `street_points` | نقطة كل 10 م على خط الشارع، ومعها المربع الأصلي ومربع التربة المستخدم والمسافة بينهم | 116,158 |
| `soil_cells` | مربعات SoilGrids (250 م)، و`is_valid=0` يعني المربع محذوف لأنه عمراني | 6,745 |
| `soil_values` | لكل مربع: 13 خاصية × 5 أعماق (0–100 سم) × المتوسط وQ05 وQ50 وQ95 وعدم اليقين | 438,425 |
| `soil_properties` / `soil_depths` | أسماء الخصائص ووحداتها، والأعماق | 13 / 5 |
| `soil_raster_files` | كل ملف خريطة نزل من ISRIC مع رابطه وبصمته SHA-256 | 650 |

| `sources` / `meta` | المصادر والتراخيص ومعلومات البناء | |

## العروض الجاهزة (Views)
- `v_point_soil`: صف لكل نقطة × عمق × خاصية، بكل القيم.
- `v_point_soil_wide`: صف لكل نقطة، وأهم الخصائص في أعمدة (مثل `clay_60_100`).
- `v_street_summary`: لكل شارع: طوله، وعدد نقاطه، ونسبة النقاط اللي قيمتها من نفس مربعها، وأبعد مسافة لمربع التربة.

## أمثلة
```sql
-- كل نقاط شارع القرطبي مع تربتها على عمق 60–100 سم
SELECT point_id, lat, lon, property_ar, mean, unit, soil_distance_m
FROM v_point_soil
WHERE street_name LIKE '%القرطبي%' AND depth_code = '60-100cm';

-- الشوارع اللي كل نقاطها لها بيانات من نفس مربعها
SELECT * FROM v_street_summary WHERE pct_direct = 100 ORDER BY length_m DESC;

-- أقرب نقطة لإحداثية معينة
SELECT point_id, street_name FROM v_point_soil_wide
ORDER BY (lat-24.7752)*(lat-24.7752) + (lon-46.5848)*(lon-46.5848) LIMIT 1;
```

## ملاحظات مهمة
- قيم التربة **تقديرات من نموذج SoilGrids بدقة 250 م**، مو فحص تربة من الموقع.
- `soil_status = 'nearest_valid_cell'` يعني مربع النقطة محذوف في SoilGrids لأنه عمراني، والقيم مأخوذة من أقرب مربع فيه بيانات. المسافة بينهم في `soil_distance_m`.
- مدى عدم اليقين واسع، مثلًا الطين عند القرطبي بين 1% و76%، فالاعتماد يكون على المتوسط مع الانتباه لهذا المدى.
- الملوحة (EC) مو موجودة، لأن SoilGrids ما يوفرها.
- يُعاد بناء القاعدة بالأمر: `python -I work/build_db.py work data_package database/wareef.db`

## التخطيط الاستراتيجي (المرحلة 1: أين نزرع أولًا؟)
جداول جديدة:
- `pois`: المساجد والمدارس داخل الحيين (OpenStreetMap + Overture Maps بعد حذف المكرر).
- `street_strategy`: لكل شارع: الفئة (`p1` أولوية قصوى … `p4`، `green` مشجّر، `none` لا يصلح)، درجة الأولوية 0–100، نوع التشجير (جانب/جانبين/جزيرة وسطية)، العرض التقديري، الأرصفة، الجزيرة، نسبة الخضرة، القرب من المساجد والمدارس، التجاري.
- `v_street_priority`: عرض مرتب بالأولوية.

الطريقة:
- الصلاحية (دليل الرياض): الجذع أكثر من 2 م عن الطريق و2 م عن السور ← الرصيف أو الجزيرة 4 م على الأقل، و6 م للأشجار الكبيرة.
- العرض: خط المباني (Microsoft) ناقص ارتداد 2 م للسور، مقرب للعروض القياسية؛ الطريق = max(مسارات OSM، 60% من العرض). تقدير يحتاج تحقق ميداني.
- الخضرة الحالية: Sentinel-2 L2A بتاريخ 2026-11-15، NDVI ≥ 0.20 في شريط الزراعة.
- الأولوية = 35% نقص التشجير + 30% القرب من المساجد/المدارس (مشي ≤ 400 م على شبكة الشوارع) + 20% تجاري + 15% سعة التشجير.
